# Architecture decision records

Each decision others will build on gets one file: `NNNN-short-title.md`, numbered in order. Copy
[0000-template.md](0000-template.md). Once an ADR is accepted, don't edit it. To change the decision, write a new ADR
that supersedes it.

The first decisions to settle are listed in [../workstreams.md](../workstreams.md#decisions-that-block-other-work).
